# SAKURA: Japanese Life RPG

Браузерный 3D-прототип симулятора повседневной жизни школьника в японском районе.

## Запуск
```bash
npm install
npm run dev
```
Откройте адрес Vite в браузере. Для production-сборки: `npm run build`.

## Уже реализовано
- 3D-сцена района: школа, дом, конбини, станция, дороги и сакуры.
- Управление WASD/стрелками и сенсорными кнопками.
- Камера от третьего и первого лица.
- Интерактивные локации рядом с персонажем.
- HUD с внутриигровым временем, йенами, энергией и настроением.
- Автосохранение позиции в localStorage.

## Статус
Ранняя игровая основа. Персонаж пока представлен простой 3D-моделью-заглушкой; NPC, полноценные интерьеры, задания и облачные сохранения запланированы для следующих этапов.
